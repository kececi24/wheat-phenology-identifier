# Pipeline Diagram Generator

This directory contains [`generate_network_pipeline.py`](generate_network_pipeline.py), the automated script used to generate publication-quality architectural schematics for the DINOv3 BBCH network.

## Output Media

The rendered figures and schematics are preserved in the central documentation assets:
- **PNG Diagram**: [`docs/figures/dinov3_bbch_network_pipeline.png`](../../docs/figures/dinov3_bbch_network_pipeline.png)
- **Vector PDF**: [`docs/figures/dinov3_bbch_network_pipeline.pdf`](../../docs/figures/dinov3_bbch_network_pipeline.pdf)

For full architectural documentation, see the [DINOv3 Temporal Pipeline Guide](../../docs/dinov3-pipeline.md).
